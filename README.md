# S.C.O.P.E.
## Smart Cross-camera Observation and Person Evaluation

> **An AI-powered intelligent surveillance system for real-time person detection, multi-camera tracking, cross-camera re-identification, and event-driven security monitoring.**

S.C.O.P.E. transforms conventional CCTV infrastructure into an intelligent, real-time decision support system by combining computer vision, deep learning, and event-driven analytics. The platform enables continuous person tracking across multiple camera feeds, helping security personnel monitor incidents proactively instead of relying solely on recorded footage.

Inspired by a real theft incident at IIT Ropar, this project addresses a key limitation of traditional surveillance systems—the inability to maintain identity continuity across cameras and generate actionable alerts in real time. Beyond its technical implementation, the project demonstrates how AI can enhance operational efficiency, improve campus security, and support scalable smart-surveillance deployments.

# Why S.C.O.P.E.?

# Core Pipeline

## 1. Person Detection

The system employs **YOLOv11m** for fast and accurate real-time person detection. A dual-confidence strategy helps preserve identity continuity during temporary occlusions and low-confidence detections.

---

## 2. Motion Prediction

A **Kalman Filter** predicts object positions across consecutive frames, ensuring stable tracking even when detections are temporarily lost.

---

## 3. Multi-Stage Cascade Tracking

The tracking pipeline uses a multi-stage assignment strategy to improve:

- Identity stability
- Occlusion handling
- Track continuity
- Cross-camera consistency

---

## 4. Cross-Camera Re-Identification

Each detected individual is represented using a **512-dimensional embedding** generated by **OSNet**.

Cross-camera matching is performed using:

- Vectorized similarity search
- Margin-based filtering
- Transit-time validation

allowing the system to maintain a consistent global identity across multiple camera feeds.

---

## 5. Event-Driven Architecture

Instead of continuously transmitting raw tracking data, the backend emits meaningful security events such as:

- TRACK_ACTIVATED
- PERSON_REIDENTIFIED
- ALERT_TRIGGERED
- TRACK_TERMINATED

Each event includes:

- Identity information
- Camera source
- Timestamp
- Contextual metadata

---

## 6. Real-Time Dashboard

The centralized dashboard enables operators to:

- Monitor live camera feeds
- Track individuals across cameras
- Visualize movement history
- Access event logs
- Receive instant security alerts

Persistent Socket.IO connections ensure real-time synchronization between backend and frontend.

# Performance Optimizations

## Manhattan Distance Pre-Gate

A lightweight L1-distance filter removes spatially unlikely track-detection pairs before expensive computations.

```math
d_{L1}(x,y)=|x_1-y_1|+|x_2-y_2|
```

---

## Min-Heap Embedding Pool

Each identity maintains a bounded collection of high-confidence embeddings using a min-heap to improve robustness against noisy samples.

```text
Insertion Complexity: O(log k)
```

---

## Vectorized Gallery Matching

Identity matching uses optimized vectorized matrix operations instead of sequential comparisons, significantly improving runtime efficiency.

---

## Dual Buffer Structure

A deque and hash-map based dual buffer enables:

- Constant-time insertion
- Fast retrieval
- Efficient identity revival
- Ordered eviction

```text
Average Complexity: O(1)
```

---

## Multi-Stage Cascade Assignment

The assignment process is decomposed into multiple stages to prioritize stable tracks and reduce identity fragmentation.

```text
Complexity: O(max(T,D)^3)
```
